# ⚡ Productivity Dashboard

A clean and simple productivity dashboard that brings your daily tools into one place: a To-Do list, a Daily Planner, a Pomodoro timer, live weather and motivational quotes.

Built with HTML, CSS and JavaScript.

## 🔗 Live Demo
https://nijamkh0.github.io/productivity-dashboard/

## ✨ Features
- ✅ **To-Do List**: add tasks, mark them as important, and complete them
- 🗓️ **Daily Planner**: plan your day hour by hour (6 AM to 11 PM)
- 💬 **Motivational Quotes**: a fresh quote every time you open it
- ⏱️ **Pomodoro Timer**: 25 minute work sessions with 5 minute breaks
- 🌦️ **Live Date, Time and Weather**: real-time clock and current weather
- 🎨 **Theme Switcher**: switch between multiple color themes
- 💾 **Auto Save**: tasks and planner data are saved in your browser (localStorage)

## 🛠️ Built With
- HTML5
- CSS3 (CSS variables, Flexbox, custom fonts)
- JavaScript (ES6)
- [WeatherAPI](https://www.weatherapi.com/) for live weather
- Motivational Spark API for quotes
- [Remix Icon](https://remixicon.com/)

## 📚 What I Learned
- DOM manipulation and event handling
- Saving and loading data with `localStorage`
- Fetching data from APIs using `fetch()` and `async/await`
- Building a timer with `setInterval`
- Changing themes using CSS variables
- Deploying a project with GitHub Pages

## 🚀 Run Locally
1. Clone the repository
   ```
   git clone https://github.com/nijamkh0/productivity-dashboard.git
   ```
2. Open the project folder
3. Open `index.html` in your browser

> Note: To use the weather feature, add your own API key from [weatherapi.com](https://www.weatherapi.com/) in `script.js`.
